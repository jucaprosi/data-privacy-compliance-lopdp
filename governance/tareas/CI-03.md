# CI-03 · Playwright sin repetir commit

**Objetivo.** Ahorrar de 7 a 9 min por cada PR que reutiliza la corrida de su push; hoy Pytest se reutiliza y Playwright no.

## Entrega
- `Playwright Frontend` no corre si la corrida está cubierta, y solo se adopta una corrida cuyo Playwright pasó.
- `resultado_del_arnes`, en `scripts/corrida_cubierta.py`, exige también el Playwright del push: hoy solo mira los arneses, y con Playwright omitido un fallo en el push quedaría adoptado.
- Una prueba del flujo fija esa condición.

## No hagas
- No cambiar la lista de checks obligatorios de `main`.

## Hecho cuando
Un commit con push y PR ejecuta Playwright una sola vez, y un Playwright fallido en el push no se adopta.

## Estado

El código está integrado (PR #320), pero el árbitro no está cumplido: ningún PR real mostró Playwright omitido con el check obligatorio aprobado, y la no adopción de un Playwright fallido solo tiene pruebas unitarias.

Solo un PR con cabeza `dev/` puede adoptar una corrida: las ramas `tarea/` no generan push y hacia `main` no se adopta. Los PR de `tarea/` ya corren Playwright una vez (corrida 41533574219), así que el ahorro de 7 a 9 min no aplica al flujo actual. Se decidió no añadir `tarea/**` a `on.push`.

Se cierra con el primer PR real que cumpla el árbitro, o con una decisión del propietario que lo cambie.
