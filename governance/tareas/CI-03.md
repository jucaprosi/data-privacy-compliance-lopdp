# CI-03 · Playwright sin repetir commit

**Objetivo.** Ahorrar de 7 a 9 min por cada PR que reutiliza la corrida de su push; hoy Pytest se reutiliza y Playwright no.

## Entrega
- `Playwright Frontend` no corre si la corrida está cubierta, y solo se adopta una corrida cuyo Playwright pasó.
- Una prueba del flujo fija esa condición.

## No hagas
- No cambiar la lista de checks obligatorios de `main`.

## Hecho cuando
Un commit con push y PR ejecuta Playwright una sola vez, y un Playwright fallido en el push no se adopta.
