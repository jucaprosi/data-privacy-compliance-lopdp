# CI-35 · Índice de tareas y sus pruebas válidos con 0 fichas pendientes

**Contrato:** `governance/especificaciones/CI-35.md` (manda sobre esta ficha).

**Origen.** Pedido del CTO (2026-11-21). Con DEMO-07 y GCP-05b cerradas (#922 y #923), main tuvo 0 fichas pendientes y quedó en rojo hasta #925. Es un estado legítimo, pero el índice y tres pruebas suponen que siempre hay alguna. Es el patrón de CI-34 (Aporte 120).

## Entrega
- `validar_contra_arbol` acepta 0 fichas no hechas; conserva el error si no se carga ninguna ficha.
- Las tres pruebas usan una muestra sintética fija y, si las hay, las fichas reales.
