# QA-03 · ¿Qué criterios del MVP están demostrados?

**Objetivo.** El PRD (§9) fija 13 criterios de aceptación del MVP. Las 63 tareas están hechas, pero nadie ha comprobado criterio por criterio qué prueba demuestra cada uno. Antes de redactar más tareas hace falta saber qué falta, con evidencia y no de memoria.

## Entrega
`governance/apoyo/AUDITORIA_CRITERIOS_MVP.md` con:
- **Una tabla, una fila por criterio** (los 13 del PRD §9, con su número y texto abreviado): árbitro que lo demuestra (ruta del archivo y nombre de la prueba o del verificador), qué afirma exactamente esa prueba, y estado: **cubierto**, **parcial** (dice qué parte falta) o **sin árbitro**.
- Para cada «cubierto»: el comando exacto que lo ejecuta, para que el coordinador lo compruebe. Sin comando, el criterio no puede marcarse cubierto.
- Un criterio es «cubierto» solo si la prueba **fallaría** si el comportamiento faltara. Una prueba que solo comprueba que algo existe, o que el código compila, cuenta como «parcial».
- Para cada «parcial» y «sin árbitro»: un **borrador de ficha** (objetivo, propiedad propuesta, árbitro propuesto, dependencias) en una sección aparte, para que el coordinador lo convierta en tarea. Borrador, no ficha: no se crean archivos en `governance/tareas/`.
- Una sección **«No verificado»** con lo que no se pudo comprobar.

## Cómo se trabaja
- Solo lectura del código, las pruebas, los verificadores y la documentación. No se escribe código ni se modifican pruebas.
- Sin base de datos ni credenciales: el agente localiza y lee las pruebas; ejecuta solo las que no necesitan base de datos (por ejemplo, las de frontend con la API simulada o las unitarias), y para las que la necesitan deja el comando para el coordinador.
- Se buscan los rastros (`git grep -F "¤..."`) y los invariantes citados en el PRD (por ejemplo `INV_LOPDP_DPO_INDEPENDENCE`) antes de buscar en lenguaje natural.

## Límites
- No implementa nada de lo que falte.
- No cambia el PRD: si un criterio está desactualizado respecto al código (por ejemplo, el número de tablas con RLS del criterio 11), lo señala en la tabla.

## Hecho cuando
- Su árbitro se cumple y `python scripts/generar_indice_tareas.py --verificar` da 0. No modificó ningún archivo fuera de su propiedad.
