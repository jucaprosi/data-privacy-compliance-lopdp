# CI-36 · Node 22 LTS alineado en imágenes, CI y engines del frontend

**Contrato:** `governance/especificaciones/CI-36.md` (manda sobre esta ficha).

**Origen.** Pedido del CTO (2026-11-21). Al construir web:188d207c, npm avisa EBADENGINE: react-dropzone@20.1.2, attr-accept@4.0.0 y file-selector@5.0.1 piden node >= 22. Las imágenes y el CI usan Node 20.

## Entrega
- Node 22 en las etapas de compilación, en la de ejecución (alpine con `nodejs` 22) y en `engines`.
- Un árbitro que compara la versión mayor de Node en las imágenes, en `engines` y en el CI.

## Límites
- Las cuatro líneas `node-version` de `.github/workflows/zero-regression-pipeline.yml` las cambia el propietario, en un commit suyo sobre la rama de esta ficha y antes de fusionarla.
