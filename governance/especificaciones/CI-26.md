Hecho medido en `origin/main` 3554924e:
- las dos funciones llaman a `git diff --name-only` con la configuración por defecto, `core.quotepath=true`;
- una ruta no ASCII sale entre comillas y con escapes octales, por ejemplo `"governance/Metodolog\303\255a de trabajo.md"`, y no casa con ninguna entrada de `propiedad`;
- la llamada de `verificar_reparto.py` no fija `encoding`, así que en Windows decodifica con la página de códigos del sistema.

## 2. API

Interfaz del lector común:

```python
def archivos_del_diff(base: str, cabeza: str, raiz: Path) -> list[str]:
    """git -c core.quotepath=off diff --name-only -z base...cabeza, en bytes, decodificado en UTF-8 y partido por NUL."""
```

Si `git` termina con un código distinto de 0, lanza `subprocess.CalledProcessError`, como ahora.

## 3. Reglas

- **R1 · Rutas literales.** El lector ejecuta `git -c core.quotepath=off diff --name-only -z <base>...<cabeza>`. Captura la salida en bytes, la decodifica en UTF-8 y la parte por `\0`, sin entradas vacías. Una ruta con tilde, espacio o salto de línea sale entera y sin comillas.
- **R2 · Un solo lector.** Los dos árbitros obtienen las rutas del diff solo a través de `scripts/_git_diff.py`. Lo que hacen con esas rutas no cambia.
- **R3 · Diff de exenciones intacto.** `_diff_de_exenciones` de `verificar_alcance_pr.py` (`--unified=0` sobre un archivo de ruta ASCII fija) no cambia.
- **R4 · Pruebas en repositorio temporal.** Las pruebas crean un repositorio con `tmp_path` y `git init`, con un commit que añade «governance/Metodología de trabajo en equipo.md». No dependen de la configuración global de git ni del repositorio real. Sin `import yaml` (lector común `tests/_lector_yaml.py`).
- **R5 · Archivos cedidos.** `frontend/playwright.config.ts` y `tests/test_ci16_pruebas_sin_proyecto.py` son de esta ficha solo para conservarlos con dueño; CI-26 no los cambia.
- **R-ADPA · Ortogonalidad ZERAG (`CI-26`).** `scripts/_git_diff.py` solo importa la biblioteca estándar. Los dos árbitros lo cargan como cargan hoy sus módulos hermanos de `scripts/`.

## 5. Aceptación

| Escenario | Prueba |
| :--- | :--- |
| **Dado** el repositorio temporal, **cuando** el árbitro de alcance revisa una rama cuya ficha posee la ruta con tilde, **entonces** no marca alcance excedido. Mutación m1: un lector sin `core.quotepath=off` deja la ruta entre comillas y la prueba falla. | `tests/test_verificar_alcance_pr.py` |
| **Dado** el mismo repositorio, **cuando** `verificar_reparto --rama` revisa el diff contra «Escribe», **entonces** R5 no da hallazgo. Mutación m2: el mismo lector sin `core.quotepath=off` hace fallar la prueba. | `tests/test_reparto.py` |
