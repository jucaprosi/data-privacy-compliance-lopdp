## 1. Datos

Sin datos persistentes. Lee `GET /diagnostico/resultados` (DIAG-03, con la forma de indicadores de DIAG-08), que responde `{"resultados": [...], "cadena_integra": bool, ...}` con el más reciente primero; usa `resultados[0].indicadores` (`IndicadoresSellados` de `features/diagnostico/domain/resultados.py`):

| Campo | Tipo | Uso en el tablero |
| :--- | :--- | :--- |

| `preguntas_evaluadas`, `preguntas_aplicables`, `cobertura` | `int`, `int`, `float` | Nota de cobertura bajo las tarjetas |

Las tareas con fecha salen de la hoja de ruta ya expuesta por `/roadmaps`.

## 2. API

Sin API nueva.

## 3. Reglas

- **R1 · Sin cifra única.** Ningún elemento muestra un valor calculado a partir de dos o más dimensiones (promedio, suma, máximo, «nivel global» o porcentaje de la organización). El frontend no recalcula ninguna dimensión: muestra el valor y la escala que devuelve la API.
- **R2 · Conformidad.** `cumplimiento = true` ⇒ «Conforme»; `false` ⇒ «No conforme». Nunca se convierte en porcentaje.
- **R3 · Sin datos.** Si la API no devuelve resultados, se muestra «Aún no hay un diagnóstico sellado» con enlace al assessment; ninguna tarjeta muestra 0 ni «—» como si fuera un resultado.
- **R4 · Semáforo de tareas.** Para cada tarea no `completada` con `end_date`: `vencida` si `end_date < hoy`; `por vencer` si `hoy ≤ end_date ≤ hoy + 7`; `en plazo` en otro caso. `hoy` en `America/Guayaquil`.
- **R6 · Escala anterior.** Si `indicadores.escala = "anterior"`, la tarjeta de Madurez muestra «Diagnóstico sellado con la escala anterior; vuelve a sellar» y ningún nivel.
- **R5 · Cadena alterada.** Si `cadena_integra = false`, sobre las tarjetas se muestra «La cadena de resultados del diagnóstico no es íntegra; consulta al DPO» en `role="alert"`.

## 4. Interfaz

Cuatro tarjetas en este orden: Madurez, Conformidad, Evidencia, Riesgo; contador «Brechas críticas abiertas: N»; nota «Evaluadas X de Y preguntas aplicables»; semáforo de tareas con los tres conteos. Los componentes de tarjeta y semáforo viven en `frontend/src/components/tableros/` para que los reutilice la cartera (ORG-15).

## 5. Aceptación

| Escenario | Prueba |
| :--- | :--- |
| **Dado** un resultado sellado simulado, **entonces** se ven las cuatro tarjetas y el contador de brechas críticas con los valores de la API. | `tableros/organizacion.spec.ts › cuatro dimensiones` |
| **Dado** ese resultado, **entonces** el texto de la página no contiene un porcentaje global ni las palabras «nivel de cumplimiento», «puntaje global» o «promedio». Mutación: añadir el promedio de las cuatro dimensiones hace fallar la prueba. | `tableros/organizacion.spec.ts › sin cifra única` |
| **Dado** la API sin resultados, **entonces** aparece el aviso y el enlace al assessment, y ninguna tarjeta. | `tableros/organizacion.spec.ts › sin datos` |
| **Dado** tareas con fin ayer, en 3 días y en 30 días, **entonces** el semáforo cuenta 1 vencida, 1 por vencer y 1 en plazo. | `tableros/organizacion.spec.ts › semáforo` |
