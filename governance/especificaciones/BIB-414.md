# BIB-414 · Pantalla de capacidades editoriales
`¤sdd` `¤arbitro`

## 1. Datos

Sin tablas. Usa la API de BIB-411 y la navegación de BIB-412, sobre `origin/main` 64802550.

## 2. API

Cliente `lib/plataforma/capacidadesEditoriales.ts` sobre `GET /biblioteca/capacidades/equipo`, `POST …/equipo/{usuario_id}/conceder`, `POST …/equipo/{usuario_id}/retirar` y `GET …/equipo/historial`, con la identidad de operador de BIB-412.

## 3. Reglas

- **R1 · Tabla del equipo.** Una fila por operador activo, con nombre, correo, «Aún no ha entrado» si `ha_entrado = false`, y tres capacidades: Editor, Revisor técnico y Publicador. Ningún texto nombra la revisión jurídica.
- **R2 · Conceder y retirar.** Un diálogo con motivo obligatorio. La fila propia está desactivada, con el texto fijo del UX/UI.
- **R3 · Errores.** Cada código de BIB-411 tiene su texto fijo; nunca se muestra el mensaje crudo del servidor.
- **R4 · Historial.** Concesiones y retiros, con quién, motivo y fecha.
- **R-SP · Sin prohibiciones** (GEN-01 R3).
- **R-ADPA · Ortogonalidad ZERAG (`BIB-414`).** Solo los archivos de la propiedad.

## 4. Interfaz

Parte de pantalla del UX/UI, §2 y §3 de `UXUI_PARTE_PANTALLA_BIBLIOTECA_OPERADORES.md`: tabla, diálogo, historial, fila propia, textos de error y accesibilidad. Manda el UX/UI.
