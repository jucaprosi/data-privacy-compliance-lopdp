# FE-25 · Ficha resumen de la organización fija bajo la barra superior, con las cuatro dimensiones y las alertas abiertas
`¤sdd` `¤frontend-ide` `¤tablero-dimensiones`

## 1. Datos

Sin datos persistentes. Lee la fila de la organización activa en `GET /organizacion/cartera` (ORG-15) y `GET /organizacion/me/roles`.

## 2. API

Sin API nueva.

## 3. Reglas

- **R1 · Contenido.** Nombre, RUC, sector, tamaño, naturaleza, DPO (nombre del `dpo` vigente), consultor (`implementador` vigente), contadores de alertas y cuatro semáforos.
- **R2 · Sin cifra única** (`INV_LOPDP_MULTIDIMENSIONAL_METRICS`).
- **R3 · Reactividad.** Al cambiar de organización (FE-21) se vuelve a pedir la fila; mientras carga, esqueleto, nunca ceros.

## 4. Interfaz

Barra de 56 px bajo `DashboardHeader`, colapsable; en móvil, una línea con nombre y alertas.

## 5. Aceptación

| Escenario | Prueba |
| :--- | :--- |
| **Dado** la fila simulada, **entonces** se ven nombre, RUC, DPO, alertas y cuatro semáforos; el texto no contiene «%» global. Mutación: añadir promedio hace fallar la prueba. | `layout/ficha-resumen.spec.ts › sin cifra única` |
| **Dado** el cambio a otra organización, **entonces** la ficha muestra la nueva en menos de un ciclo de carga. | `layout/ficha-resumen.spec.ts › cambio de organización` |

## 6. Trazabilidad

- Ficha: `governance/tareas/FE-25.md`. Especificación de referencia: `governance/especificaciones/README.md`.
- PRD apartado 8 («Estructura común de pantalla», zona 3); Doctrina 4.
