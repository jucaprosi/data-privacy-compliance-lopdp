# FE-23 · Patrón único de asistente
`¤sdd` `¤asistente` `¤frontend-ide`

## 1. Datos

Sin datos persistentes. Contrato en `frontend/src/components/asistente/tipos.ts`:

```ts
export interface PasoAsistente {
  id: string;
  titulo: string;
  opcional: boolean;
  validar: () => string | null;          // null = válido; texto = motivo visible
  contenido: React.ReactNode;
}

export interface AsistenteProps {
  pasos: PasoAsistente[];                 // 1..20
  guardar: (pasoId: string) => Promise<void>;
  alTerminar: () => void;
  pasoInicial?: number;                   // por defecto 0
}
```

## 2. API

Sin API nueva: el asistente no llama a la API; lo hace `guardar`, que provee la sala dueña de los datos.

## 3. Reglas

Estado: índice `i ∈ [0, n−1]`, mensaje `m ∈ {null, texto}`, `ocupado ∈ {true, false}`.

- **R1 · Siguiente.** Si `validar_i() ≠ null` ⇒ `m := validar_i()`, `i` no cambia, no se llama a `guardar`. Si no ⇒ `ocupado := true`; `await guardar(id_i)`; si resuelve ⇒ `i := i + 1` (o `alTerminar()` si `i = n−1`), `m := null`; si rechaza ⇒ `i` no cambia, `m := "No se pudo guardar este paso. Intenta de nuevo."`. Siempre `ocupado := false` al terminar.
- **R2 · Saltar.** Solo si `opcional_i`; no valida ni guarda; `i := i + 1`.
- **R3 · Anterior.** Si `i > 0` ⇒ `i := i − 1`, sin validar ni guardar.
- **R4 · Concurrencia.** Con `ocupado = true`, los tres botones están deshabilitados.
- **R5 · Progreso.** Texto «Paso `i+1` de `n`»; los pasos anteriores se marcan como completados o saltados según cómo se dejaron.

## 4. Interfaz

Lista de pasos (el actual con `aria-current="step"`), título del paso con el foco al cambiar, contenido, mensaje `m` en `role="alert"`, y botones «Anterior», «Saltar» (solo en opcionales) y «Siguiente» / «Terminar» en el último. Navegable con teclado.

## 5. Aceptación

| Escenario | Prueba |
| :--- | :--- |
| **Dado** un paso obligatorio inválido, **cuando** se pulsa «Siguiente», **entonces** se muestra su motivo, no avanza y `guardar` no se llamó. Mutación: avanzar sin validar hace fallar la prueba. | `asistente/flujo.spec.ts › no avanza inválido` |
| **Dado** un paso válido y `guardar` que resuelve, **entonces** avanza al siguiente y el foco está en su título. | `asistente/flujo.spec.ts › avanza y enfoca` |
| **Dado** `guardar` que rechaza, **entonces** se queda en el paso y muestra el aviso. | `asistente/flujo.spec.ts › error al guardar` |
| **Dado** un paso opcional, **entonces** «Saltar» existe y avanza; en uno obligatorio, no existe. | `asistente/flujo.spec.ts › saltar` |
| **Dado** `guardar` en curso, **entonces** los botones están deshabilitados. | `asistente/flujo.spec.ts › ocupado` |
